# Источники для изучения Python до уровня Senior

## 1. Курсы, которые разобраны в репозитории
- Хирьянов, «Практика программирования на Python 3» (2020): https://www.youtube.com/playlist\?list\=PLRDzFCPr95fIDJUvFxvzWxg-V9BmZlMMe
- Материалы кафедры (МФТИ CS): https://github.com/mipt-cs и http://cs.mipt.ru/python
- Конспекты лекций Хирьянова (репозиторий `pdf-textbook-python3` в организации mipt-cs): https://github.com/mipt-cs
- Эрик Мэтиз, *Python Crash Course* (3-е изд.) — книга, основа блока 1

## 2. Язык и стиль (официальные документы)
- Официальный туториал: https://docs.python.org/3/tutorial/
- Модель данных: https://docs.python.org/3/reference/datamodel.html
- PEP 8, стиль кода: https://peps.python.org/pep-0008/
- PEP 20, Zen of Python: https://peps.python.org/pep-0020/
- PEP 257, docstrings (тема лекции 5): https://peps.python.org/pep-0257/
- PEP 484, аннотации типов: https://peps.python.org/pep-0484/
- Real Python: https://realpython.com/
- Allen Downey, *Think Python* (бесплатно): https://allendowney.github.io/ThinkPython/
- Pygame: https://www.pygame.org/docs/

## 3. Продвинутый Python (книги)
- Luciano Ramalho, *Fluent Python*, 2nd ed.: https://www.fluentpython.com/
- Brett Slatkin, *Effective Python*: https://effectivepython.com/
  (в русском переводе названия книг могут отличаться)

## 4. Алгоритмы и Computer Science
- Хирьянов, курс «Алгоритмы и структуры данных на Python» — искать на YouTube по названию
- Aditya Bhargava, *Grokking Algorithms*
- Cormen et al., *Introduction to Algorithms* (CLRS) — справочник
- VisuAlgo, визуализация алгоритмов: https://visualgo.net/

## 5. Внутреннее устройство CPython
- Developer's Guide: https://devguide.python.org/
- Модуль `dis` (байт-код): https://docs.python.org/3/library/dis.html
- Python behind the scenes (цикл статей): https://tenthousandmeters.com/blog/python-behind-the-scenes-1-how-the-cpython-vm-works/
- Anthony Shaw, *CPython Internals*

## 6. Рефакторинг, чистый код, архитектура
- Refactoring Guru (рефакторинг и паттерны): https://refactoring.guru/ru/refactoring
- Martin Fowler, *Refactoring*: https://refactoring.com/
- Robert Martin, *Clean Architecture*
- Percival & Gregory, *Architecture Patterns with Python* (Cosmic Python, бесплатно): https://www.cosmicpython.com/

## 7. Git и процесс
- Pro Git (на русском): https://git-scm.com/book/ru/v2
- Conventional Commits: https://www.conventionalcommits.org/
- GitHub Docs: https://docs.github.com/

## 8. Асинхронность, тесты, БД, инфраструктура
- asyncio: https://docs.python.org/3/library/asyncio.html
- Caleb Hattingh, *Using Asyncio in Python*
- pytest: https://docs.pytest.org/
- mypy: https://mypy.readthedocs.io/
- Ruff (линтер): https://docs.astral.sh/ruff/
- PostgreSQL: https://www.postgresql.org/docs/
- SQLAlchemy 2.0: https://docs.sqlalchemy.org/en/20/
- Docker: https://docs.docker.com/
- GitHub Actions: https://docs.github.com/en/actions

## 9. Среда
- Arch Wiki, Python (подходит для Manjaro): https://wiki.archlinux.org/title/Python
