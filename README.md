# Практикум по Python: Эрик Мэтиз и лекции МФТИ (Тимофей Хирьянов)

Репозиторий содержит практические задания, конспекты и программные решения, созданные в процессе углубленного изучения базового и алгоритмического Python.

Материал логически разделен на два независимых блока:
1. **Академический задачник:** упражнения по книге Эрика Мэтиза *«Изучаем Python» (Python Crash Course)*.
2. **Алгоритмическая база:** задачи и примеры из курса лекций МФТИ *«Практика программирования на Python»* (лектор — Тимофей Хирьянов).

Тематическое наполнение разделов
Блок 1. Эрик Мэтиз — «Изучаем Python»

Каждая папка соответствует отдельной главе учебника и включает:

    Базовые примеры из теории автора с отработкой синтаксиса.

    Подкаталоги exercise/ с решением сквозных самостоятельных упражнений:

        Глава 2: Строки, форматирование f-строками, регистры (title(), lower()), числа, удаление пробелов (strip()).

        Глава 3: Индексация, изменение списков на лету (append(), insert(), pop(), remove()), сортировка (sort(), sorted(), reverse()).

        Глава 4: Итерация списков через for, числовые последовательности range(), агрегатные функции min(), max(), sum(), срезы списков.

        Глава 5: Булева логика, проверка значений в списке оператором in / not in, каскады if-elif-else.

        Глава 6: Вложенные структуры (список словарей, словари со списками), обход ключей и значений, работа с get().

        Глава 7: Управление потоком цикла с помощью break и continue, наполнение словарей через пользовательский ввод.

        Глава 8: Декомпозиция кода, передача списков в функции с их модификацией, произвольное число аргументов (*args, **kwargs).

Блок 2. МФТИ — Лекции Тимофея Хирьянова

Курс сосредоточен на структурном программировании, оптимизации и внутреннем устройстве языка:

    Особенности работы циклов с предусловием и постусловием в интерпретаторе CPython.

    Реализация классических алгоритмических паттернов поиска и фильтрации.

    Сравнение производительности и применение хешируемых типов (tuple, frozenset) против изменяемых (list, dict).

Установка и запуск
1. Клонирование репозитория
```bash

git clone [https://github.com/Ramazan101/Eric-Metz-Lear-Python-.git](https://github.com/Ramazan101/Eric-Metz-Lear-Python-.git)
cd Eric-Metz-Lear-Python-
```
2. Настройка виртуального окружения
```bash

python -m venv .venv
source .venv/bin/activate  # Для Linux / macOS
```
3. Установка зависимостей (при необходимости)
```bash

pip install -r requirements.txt
```
4. Запуск любого скрипта

Запуск конкретного упражнения или лекции производится прямой передачей пути интерпретатору:
```bash

# Пример запуска скрипта из книги Мэтиза
python 01_python_crash_course_eric_matthes/chapter_08_functions/formatted_name.py

# Пример запуска лекции МФТИ
python 02_mfti_khiryanov_lectures/01_loops.py
```
